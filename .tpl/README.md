# Newcomer 使用说明

本模板提供独立运行的双语官网以及可复用的页面包。能力、安装、启动、停止与验证见根 README；路由合同见 project.json，市场资料见 template.json。

首页包含首屏入场、头像错峰、手机视差、双向应用循环带、可拖拽更新卡片、社区评价和候补名单。菜单可用 Escape 关闭，减少动态效果设置会停止循环、视差及入场位移。表单不访问网络，不保存数据。

先读 docs/ARCHITECTURE.md、docs/CUSTOMIZATION.md、docs/VERIFICATION.md、docs/LICENSE.md。任何说明都不自动授权安装、上传、发布或外部发送。截图与动效是否通过以 reports 中实际记录为准。
