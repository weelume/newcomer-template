# 动效清单与参数

参考站：https://newcomer.framer.website/ 。公开模块与实际浏览器观察交叉核对；源码参数不等同实际动效验收通过。

| 区域 | 触发与轨迹 | 参数 | 实现入口 |
|---|---|---|---|
| 首屏文案与手机 | 页面进入，y40→0，opacity0→1 | 延时0.15s，0.7s，ease[.12,.23,.17,.99] | Motion / HomePage |
| 头像与人数 | 页面进入，x-10→0 | 0.5/0.55/0.6/0.65/0.7s错峰，spring 1s | WaitlistForm / theme |
| 功能手机1/3/4 | 滚动目标，y50→-25 | spring500/60；原站4阈值1，其余0.5 | Parallax |
| 功能手机2 | 滚动目标，y-50→25 | spring500/60 | Parallax |
| 应用手机 | 滚动目标，y-50→50 | 原站offset80、阈值0.5 | Parallax |
| 应用标签 | 两行反向循环 | 10px/s，16px间距，不可拖拽，悬停同速 | Ticker |
| 更新卡片 | 横向循环、拖拽、悬停半速 | 30px/s，24px间距，可拖拽 | Ticker |
| 玻璃卡片 | 悬停y-4；评价scale1.02 | 0.3/0.45s spring | Home / theme |
| 菜单 | 开合，图标旋转，内容高度动画 | 原站spring600/40；内容0.4s tween | Shell |
| CTA | 滚动进入，y40→0 | 延时0.3/0.35s，0.7s | Home |
| 全站换页 | 全局opacity0→1 | 0.2s | Shell |

当前差异：原站 Lenis 平滑引擎未引入，使用原生滚动；滚动阈值需继续逐帧对照；原站拖拽释放惯性尚待实际比较；头像与人数已改为原站弹簧错峰；系统减少动态效果尚未实际切换验收。不得标为完整逐帧复刻完成。
