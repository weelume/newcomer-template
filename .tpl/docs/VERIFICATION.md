# 验收标准

类型检查、ESLint、内容与素材测试、生产构建均需执行并记录结果。默认中文和 `/en` 页面必须可访问；7 页共 14 个语言路由。验证语言切换保留页面、查询和锚点，菜单开关、Escape、焦点、表单错误与本地成功语义。

视口：1440×1000、834×1180、390×844，补查 320px。检查溢出、手机操作、单主滚动区、原生滚动条、离开后的样式恢复。市场截图应来自真实页面，不将设计素材冒充验收截图。

动效逐项记录初始、运行、结束状态。首屏 40px 上移、0.7 秒自定义缓动；头像错峰；五处手机滚动视差；应用双向 10px/s；更新循环 30px/s、悬停半速、拖拽续播；卡片悬停；菜单进出；减少动态效果。未运行的项目应明确记为未验证。
